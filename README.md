# Makmoura · مكمورة

A family app where children complete daily tasks, grow a virtual balance toward a personal goal, and earn occasional shared family rewards together.

- **[DESIGN.md](DESIGN.md)**: design principles, the child and parent Home screens, the Makmoura Card, and the visual system.
- **[docs/family-rewards.md](docs/family-rewards.md)**: Family Rewards feature spec: conditions, lifecycle, frequency, data model.
- **[prototype/index.html](prototype/index.html)**: interactive, self-contained prototype. Open it in any browser.
